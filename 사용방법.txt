S.PDF 2.1

설치와 실행
S.PDF-Setup.exe → [설치 시작] → [시작하기] 순서로 진행합니다.
Windows 10/11 64비트용이며 Python이나 별도 PDF 프로그램을 설치할 필요가 없습니다.
설치 후 바탕화면과 시작 메뉴의 S.PDF로 실행합니다. Windows의 [연결 프로그램]에서도 S.PDF를 선택할 수 있습니다.
기본 PDF 연결 프로그램을 자동으로 변경하지 않습니다.

자동 업데이트
처음에는 이 설치 파일을 한 번 실행해야 합니다. 이전 2.0에는 자동 업데이트 기능이 없습니다.
실행할 때 github.com/JUNGHANGEUL/s-pdf의 최신 배포 파일을 확인합니다.
새 버전을 백그라운드에서 내려받고 파일 크기와 SHA256을 검증합니다.
문서 저장을 확인하고 S.PDF를 완전히 종료한 뒤 업데이트하며, 다음 실행부터 새 버전을 사용합니다.
종료 전에 다운로드를 끝내지 못하면 기존 버전을 계속 사용하고 다음 실행 때 다시 확인합니다.
메뉴의 [자동 업데이트 사용]으로 끄거나 [업데이트 확인]으로 직접 확인할 수 있습니다.
인터넷이 없어도 PDF 기능은 그대로 사용할 수 있습니다. 업데이트 확인에는 PDF를 보내지 않습니다.


문서와 탭
[열기] 또는 Ctrl+O로 여러 PDF를 선택하거나 파일을 창으로 끌어다 놓습니다.
상단 탭으로 파일을 전환합니다. 탭은 끌어서 순서를 바꿀 수 있고 X로 닫습니다.
문서마다 읽던 페이지와 확대 배율을 유지합니다. 파일 이름 옆의 점은 저장하지 않은 변경사항입니다.
하단 페이지 번호를 입력하거나 이전·다음 버튼으로 이동합니다.

고화질 캡처
[캡처]를 선택하고 문서에서 사각형 영역을 드래그합니다.
페이지 전체를 저장하려면 오른쪽에서 [현재 페이지 전체]를 선택합니다.
150·300·600·1200dpi와 PNG/JPG 형식을 고릅니다.
[이미지로 저장] 또는 [클립보드에 복사]를 누릅니다.
문서 자체를 지정 해상도로 그리므로 화면 확대 배율과 관계없이 저장됩니다.
스캔·사진 원본에 없는 세밀함이 복원되는 것은 아닙니다.
[일괄 캡처]는 페이지 범위를 지정해 저장합니다. 영역을 선택했다면 각 페이지의 같은 비율 위치를 사용합니다.
출력 이미지가 1억 픽셀을 넘으면 해상도나 영역을 줄여주세요.

페이지 구성
[페이지 구성]에서 Ctrl·Shift로 여러 페이지를 선택합니다.
페이지를 끌어 순서를 바꾸거나 [앞으로 이동]·[뒤로 이동]을 사용합니다.
[파일 추가]는 현재 문서 뒤에 페이지를 넣습니다.
[파일 합치기]는 목록을 끌어 순서를 정한 뒤 새 문서로 합칩니다. 열려 있는 탭의 변경사항도 포함합니다.
[선택 삭제]·[회전]을 사용한 뒤 저장합니다. Ctrl+Z로 되돌릴 수 있습니다.
[추출]은 필요한 페이지만 새 PDF로 저장합니다. [분할]은 지정한 개수씩 파일을 나눕니다.
페이지 범위 입력 예: 1,3-5,8

글자 수정과 추가
[텍스트 편집] → [기존 글자 수정]에서 글자를 클릭합니다.
오른쪽에서 내용·글꼴·크기·굵기·색상을 고르고 [수정 내용 적용]을 누릅니다.
선택한 글자 내용은 PDF에서 실제로 제거한 뒤 새 텍스트로 대체합니다.
원본 글꼴 대신 선택한 글꼴을 사용하므로 적용 후 배치와 줄 길이를 확인해주세요.
새 글자가 길면 글자 크기를 줄이거나 [텍스트 추가]로 더 넓은 영역을 선택합니다.
[텍스트 추가]는 문서에서 영역을 드래그한 뒤 내용을 입력합니다.
기울거나 세로로 배치된 기존 글자는 직접 교체를 제한하며 새 텍스트 영역을 사용할 수 있습니다.

스캔 문서와 OCR
[문자 인식 · OCR]에서 페이지 범위와 한국어·영어를 선택합니다.
기존 글자가 있는 페이지는 건너뛰고 이미지 페이지에 검색 가능한 글자 층을 추가합니다.
OCR은 로컬에서 실행되며 언어 파일이 포함되어 있습니다.
인식 결과는 원본 상태와 글꼴에 따라 달라질 수 있으므로 확인이 필요합니다.
스캔 이미지 속 글자를 고치려면 [영역 배경도 지우기]를 사용할 수 있습니다. 흰색으로 지워지는 영역에 주변 그림이 포함되지 않았는지 확인해주세요.

주석·검색·북마크·비교
[보기]의 [주석] 메뉴에서 형광펜·사각형·화살표·메모를 선택합니다.
왼쪽 [주석 목록]에서 주석을 찾아 이동하거나 삭제할 수 있습니다.
[문서 검색] 또는 Ctrl+F로 찾습니다. [글자 선택]에서 영역을 드래그하면 글자가 클립보드에 복사됩니다.
[북마크]로 현재 페이지의 북마크를 PDF에 추가합니다.
[나란히 보기]는 다른 탭의 문서를 함께 표시합니다. [동기화]는 페이지와 스크롤 위치를 맞춥니다.

용량 줄이기
[보기]의 [용량 줄이기] 또는 오른쪽 설정 메뉴를 사용합니다.
무손실 최적화, 300dpi, 150dpi, 96dpi 이미지 압축 중 선택합니다.
별도 PDF로 저장하고 결과 용량을 확인합니다. 이미 최적화된 PDF는 더 작아지지 않을 수 있습니다.

저장·실행 취소·복구
Ctrl+S는 현재 파일에 저장합니다. Ctrl+Shift+S는 다른 이름으로 저장합니다.
편집 중에는 작업 사본을 사용합니다. 원본은 사용자가 저장할 때만 바뀝니다.
완성한 파일은 임시 파일로 저장·재확인한 뒤 교체합니다.
Ctrl+Z는 실행 취소, Ctrl+Y는 다시 실행입니다. 큰 파일의 실행 취소는 잠시 걸릴 수 있습니다.
비정상 종료 후 다시 실행하면 자동 복구를 선택할 수 있습니다.
자동 복구를 위해 문서 사본·추가한 글꼴·작업 기록이 사용자 AppData\Local\S.PDF\sessions에 저장됩니다.
정상 종료 시 작업용 사본을 정리하고, 다음 실행 때 마지막으로 열었던 파일과 위치를 복원합니다.
설정 메뉴에서 마지막 문서 자동 열기를 끌 수 있습니다.

단축키
Ctrl+O 파일 열기 / Ctrl+W 탭 닫기 / Ctrl+Tab 다음 탭
Ctrl+S 저장 / Ctrl+Shift+S 다른 이름으로 저장
Ctrl+Z 실행 취소 / Ctrl+Y 다시 실행
Ctrl+F 검색 / Ctrl+P 인쇄 / Ctrl+R 회전
Ctrl+마우스 휠 확대·축소 / Ctrl+0 화면에 맞춤
Ctrl+Home 첫 페이지 / Ctrl+End 마지막 페이지

프로그램 제거
Windows 설정 → 앱 → 설치된 앱 → S.PDF 또는 시작 메뉴의 프로그램 제거를 사용합니다.
사용자가 저장한 PDF와 설정·복구 데이터는 제거하지 않습니다.
